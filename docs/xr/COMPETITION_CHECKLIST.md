# Meta VR Start 2026 — Competition Checklist

This file is an execution checklist, not a substitute for re-reading the current official rules before submission.

## Eligibility / administration
- [ ] Meta VR Start membership approved before submission.
- [ ] Devpost account/registration complete.
- [ ] entrant/team details accurate.
- [ ] division choice reviewed against current rules.
- [ ] adaptation baseline evidence preserved.

## Adaptation evidence
Preserve:
- pre-competition commit(s);
- screenshots/build evidence;
- original web-game description;
- dated changelog of MR work.

Do not rewrite history.

## Experience
- [ ] complete primary experience without pairing controllers.
- [ ] seated play works.
- [ ] frequent interactions stay within comfortable tabletop reach.
- [ ] no essential tiny text.
- [ ] no wall-of-text onboarding.
- [ ] passthrough/real table materially changes play.
- [ ] interaction remains understandable in unfamiliar room/table conditions.
- [ ] pause/exit/recovery behavior is sane.

## First five minutes
- [ ] first action <=30 s.
- [ ] first reward <=60 s.
- [ ] first visible problem by ~3 min.
- [ ] first meaningful decision/intervention by ~4 min.
- [ ] satisfying payoff by ~5 min.

## Technical
- [ ] real target hardware tested.
- [ ] stable required framerate demonstrated.
- [ ] no critical runtime errors.
- [ ] hand tracking loss/recovery handled.
- [ ] scene/table anchoring tested across rooms.
- [ ] performance evidence captured.
- [ ] build/load path documented.

## Polish
- [ ] coherent art direction.
- [ ] machine silhouettes distinguishable.
- [ ] state communicated by shape/motion/audio, not color alone.
- [ ] spatial audio restrained and useful.
- [ ] snap/place feedback polished.
- [ ] no debug UI in submission build.

## Submission package
- [ ] English description.
- [ ] real gameplay video under current time limit.
- [ ] video leads with strongest MR-specific moment.
- [ ] screenshots from actual build.
- [ ] expected release-date field prepared.
- [ ] licenses/attributions reviewed.
- [ ] free availability requirement, if current rules require it, satisfied.
- [ ] final rules re-checked within 72 h of submission.
- [ ] submit before internal deadline, not at official last minute.
