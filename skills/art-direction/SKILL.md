# Skill: XR Art Direction

## Use when
Creating or reviewing visuals, assets, materials, UI or thumbnails.

## Read first
docs/xr/ART_DIRECTION.md

## Procedure
1. Check silhouette at tabletop distance.
2. Remove detail that does not survive that distance.
3. Keep palette semantic and restrained.
4. Ensure machine states remain understandable without labels.
5. Avoid mixed visual styles.
6. Review actual headset capture when available.
7. Test thumbnail/first-frame separately from in-game beauty.

## Reject when
- asset looks realistic but reduces readability;
- tiny labels are required;
- asset style conflicts with the rest of the diorama;
- visual effect harms comfort/performance;
- art hides the flow state.

## Evidence
Before/after screenshot or headset capture; use A/B test for major direction changes.
