# Skill: Competition Submission Evidence

## Use when
Preparing adaptation proof, competition copy, trailer, screenshots or final audit.

## Procedure
1. Re-read current official rules near submission.
2. Preserve pre-competition baseline commit evidence.
3. Separate old web functionality from new MR functionality.
4. Use only real gameplay footage for core claims.
5. Capture hands-first interaction, table dependence and strongest magic moment early.
6. Keep claims demonstrable in the build.
7. Track license/attribution status for every external asset.

## Evidence pack
- baseline commit/date;
- current commit;
- changelog;
- target-hardware test;
- gameplay capture;
- screenshots;
- performance record;
- participant test summary;
- final rules checklist.

## Stop condition
Every material submission claim maps to evidence.
