# Skill: Competition Submission Evidence

## Procedure
1. Re-read the official rules near submission (link in COMPETITION_CHECKLIST.md).
2. Preserve pre-competition baseline evidence (commits 2026-09-05 → 2026-09-23, CrazyGames submission email of 2026-09-23).
3. Separate old web functionality from new MR functionality ("new during the window" list).
4. Use only real gameplay footage captured on Quest (or the XR Simulator, labeled) for core claims.
5. Video < 3 min: open with the strongest MR moment (overflow at the real table edge + the fix) in the first seconds; show hands-only play, seated, the table mattering, gaze + pinch, the grade/progress loop.
6. Devpost write-up with one section per criterion (Innovation & Creativity; Experience Design; Technical Implementation; Polish & Presentation), each with concrete evidence (numbers from playtests, fps, features). Judges may use AI assistance: be explicit, structured and factual.
7. One-line tagline that names the signature interaction.
8. Build: APK in release channel "Competition" (Unity) or public URL (WebXR); free until the winner announcement; install tested from a clean device.
9. Track license/attribution status for every external asset.

## Evidence pack
- baseline commit/date and current commit;
- changelog (progress/PROGRESS.md);
- target-hardware test and performance record;
- gameplay capture and screenshots;
- participant test summary;
- final rules checklist with links.

## Stop condition
Every material submission claim maps to evidence.
