# Project Skills

Skills are compact task-specific operating procedures for agents.

Use:
```bash
npm run skill:new -- <skill-name>
```

Each skill should answer:
- when to use it;
- what to read first;
- procedure;
- required evidence;
- acceptance criteria;
- common failure modes;
- stop condition.

Current skills:
- xr-product-guardian
- xr-interaction-review
- gameplay-experiment
- art-direction
- performance-quest
- submission-evidence
